Rules // each role by its threshold, against the claim's scope

weakened // material adverse evidence undermines the claim, without sufficient grounds to reject it

contradicted // current evidence gives sufficient grounds to reject the claim as stated, within its declared scope and conditions; new evidence may change it

a declining confidence number alone is not weakened // a contrary observation alone is not contradicted without the claim's scope

an existing weakened record assigned under the earlier, broader reading // its owner reviews it; this profile reassigns nothing

partially supported // yellow
weakened // orange
contradicted // red

Rules // the words carry the distinction

two close pairs // supported beside partially supported, green beside yellow; weakened beside contradicted, orange beside red

simulated color-vision output is not user testing // the visible words carry each role, on its label, beside its dot or in a key

a dot beside a square tells evidence from a state // it does not tell two evidence roles apart

Usage and owners // load order and who decides what

evidence-state.css binds each role to the foundation's physical value directly: four reserved state values, the emphasis cyan and lavender-gray // load colors_and_type.css first, then spectral-state.css and evidence-state.css with surface-panel.css and surface-treatments.css, all from one design-system commit // both declare custom properties only, role values and inks on :root and the keyed label's and range's color and paint properties on their own selectors, so their place beside the other two changes no resolved value; this key loads them directly after the foundation

evidence-state.css owns the roles, their values, their ink, label and rail bindings and the not-yet-testable contract // surface-treatments.css owns the fill paint, every ink, the marker's anatomy, the bordered label and the labeled range // review-semantics.css draws the document marks on it // the consumer owns which claim carries which role, and the evidence itself
