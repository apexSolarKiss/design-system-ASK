Rules // channel discipline

function ≠ state ≠ evidence · reused hue is not identity · labels stay mandatory

fill = function · outline = an independently asserted state, or a badge or separate state marker, which a state in the fill's own color requires · marker = evidence state, or a rail, dash or labeled annotation // the same rule for each of the three functions

Usage and owners // load order and who decides what

load colors_and_type.css first, then surface-panel.css and surface-treatments.css, then three-functions.css, all from one design-system commit // the fill paint supplies each role's ink

a figure that shows state or evidence too, as the channel examples do, also loads spectral-state.css and evidence-state.css from the same commit // each binds its own roles, and the channels stay apart

three-functions.css owns the roles, their values and their inks' bindings // surface-treatments.css owns the fill paint and every ink // the consumer owns which apparatus performs which function
