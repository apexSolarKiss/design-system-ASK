Rules // sparse-signal discipline

most nodes neutral // neon only to say something

a shared value is not a shared meaning // Evidence State, Review State and Criterion Assessment bind the same physical values under their own words

Rules // the selection rule

one element, one declared scope or version // one primary state

operation established only at bounded depth // partial, with any structural or schema assurance recorded as its basis

structural or schema assurance established, operational assurance not // structural, for that scope

earned // still full-depth operational grounding · different scopes may carry separate labeled records

no ranking between structural and partial // the rule says which applies, and never reassigns an existing element's state on its own

Rules // the words carry the role

a changed assignment changes the reading task // separations measured for the old roles say nothing about the new ones

simulated color-vision output is not user testing // close pairs stay close under it, green beside yellow and violet beside magenta

every state keeps its visible words // on its label, beside its mark, or in a key

a square beside a dot tells a state from an evidence role // it does not tell two states apart

Worked applications // the roles in use

interactive spine // filled state nodes beside neutral ones, with selection and export

interactive radial // state marks filled, structure washed

Review Semantics // state squares in a document annotation

Usage and owners // load order and who decides what

load colors_and_type.css first, then spectral-state.css with surface-panel.css and surface-treatments.css, all from one design-system commit // spectral-state.css declares custom properties only, role values and inks on :root and the state label's and range's color and paint properties on their own selectors, so its place beside the other two changes no resolved value; this key loads it directly after the foundation

spectral-state.css owns the roles, their values and their bindings to ink, label and rail // surface-treatments.css owns the fill paint, every ink, the marker, the bordered label and the labeled range // the consumer owns which element carries which state, and its evidence
