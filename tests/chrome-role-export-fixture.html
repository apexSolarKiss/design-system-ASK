FOUR limbs, each biting independently. A pass on INK must never mask a
failure on MUTED — the exporter resolves the two roles on two separate
lines, so one can regress while the other stays correct.

  DEFAULT  / INK     --diagram-ink aliases --fg-1, and that value is in the
                     exported primary chrome (mark, title, stamp key).
  DEFAULT  / MUTED   --diagram-muted aliases --fg-2, and that value is in the
                     exported secondary chrome (subtitle, date line).
  OVERRIDE / INK     exported primary chrome follows --diagram-ink, not --fg-1.
  OVERRIDE / MUTED   exported secondary chrome follows --diagram-muted, not --fg-2.

"run pixel check" exports the page and scans the HEADER BAND only. That
isolation is load-bearing: the diagram body is styled from the same semantic
roles, so scanning it would satisfy every assertion no matter what the
exporter did, and the test would stop biting.
